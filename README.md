# 夜風 るる — 制作物まとめ (yorukaze-luru.github.io)

GitHub で公開しているプロジェクトを紹介する GitHub Pages サイトです。

公開URL: https://yorukaze-luru.github.io/

## 掲載プロジェクト

- [アプリカ (aprica)](https://github.com/yorukaze-luru/aprica) — ウェブサイトを本物の Android APK に変換するジェネレーター
- [Pアプリカ (paprica)](https://github.com/yorukaze-luru/paprica) — アプリカのプッシュ対応版（GeckoView + UnifiedPush）
- [AmongUsCapture v2](https://github.com/yorukaze-luru/amongus-capture-v2) — Among Us × Discord 自動ミュート
- [One-armed robber 日本語化パッチ](https://github.com/yorukaze-luru/One-armed-robber-japanese) — Steam FPS の非公式日本語化
- [YTV2](https://github.com/yorukaze-luru/YTV2) — 一覧生成 Web ツール

## 構成

- `index.html` — 単一ファイル（CSS / JS 内蔵、外部依存なし）

GitHub Pages はこのリポジトリの `main` ブランチ / ルートから公開します。
